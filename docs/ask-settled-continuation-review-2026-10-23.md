## What was implemented

An owner-only evaluation continuation reconstructs the original question frame, offered candidates and selection from complete saved records. It re-runs the actual evidence parser and requires its sealed package to equal the exact package supplied to the paid writer. It binds saved drafts to their settled receipts in the immutable campaign history.

Each reused draft must match the current writer request's model identity, instructions, complete structured prompt, schema, output allowance, thinking setting and structured-output mode. Object key order is immaterial; religious wording and array order are preserved. The full saved output is revalidated against the complete contract. Missing, malformed, ambiguous or changed inputs fail without paying for a replacement initial draft. A saved draft can be consumed once; only the existing single eligible correction may call the writer again.

The original frame, ranking and selection are not rerun. Draft reuse is not support approval: the same current rich writing/checking engine performs the unpaid checks and any eligible correction. This utility is not imported by website routes or production workers. It does not implement or accept the visitor-facing durable continuation feature.
