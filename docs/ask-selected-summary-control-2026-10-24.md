# Exact-sentence summary control

Status: implemented and offline verified behind an owner-only dependency. One live component reviewed. Not enabled on the website, not accepted as a full-answer accuracy repair.

## What changed

An optional summary path asks the existing writer to select up to four explanation IDs. Server code copies whole already-checked sentences with their exact citations and assigned question concern. The writer cannot supply new wording, merge statements, remove conditions or add advice. Unknown/duplicate IDs, extra prose and invalid envelopes are rejected whole. A hash binds the choices to the source explanations, question, requirements, originals and context; changing those while selection is pending causes withdrawal.

The optional next-step footer is absent in this mode. Its absence is supported in validation, saved-answer hydration and display. An invalid supplied footer is still rejected; normal generative writing retains its own validation. Actual steps requested by a visitor still require full question coverage.

Source claims still need their normal reviews. Every final support, meaning, conditions, coverage, consistency, directness and contribution/repetition check remains mandatory. Selection cannot turn a failed final audit into completion. The existing single shared correction limit remains; there is no fallback to prose generation in selection mode. No website setting enables this dependency.

This guarantees preservation of the supplied sentences, not their religious accuracy. It can preserve an earlier error just as exactly as a correct statement. A repeated source explanation may also be judged an unhelpful recap by final checks. Live final-check compatibility remains untested.
