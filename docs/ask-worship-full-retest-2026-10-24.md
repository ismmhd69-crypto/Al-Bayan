## Important test-setup limitation

This used the actual rich `ask` pipeline with live source research, but it was a direct invocation rather than the HTTP/SSE/browser route. It omitted the explicit parent signal supplied by the stream route. That selected a different optional Quran partial-query failure-handler branch, so one failed query could discard that query group's other results in this direct run. Therefore this is **not an exact browser-equivalent retrieval test**.

The runner was corrected **after** the paid attempt to supply the parent signal for future tests. The old/new runner hashes and the limitation are saved with the result. The paid result was not rerun or relabelled as using the corrected harness.
