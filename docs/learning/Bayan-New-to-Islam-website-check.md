# New to Islam: website implementation

19 October 2026. Built locally in Bayan at http://127.0.0.1:3000/en/start. No deployment, commit, push, database change or Ask-source expansion.

## What is built

- One course, two entrances; six chapters and 32 lessons in English, Arabic and German.
- Bayan's existing logo, fonts, page shell, colour variables, navigation and buttons. New course styles are scoped to this section.
- Full prepared lessons, explanations, guidance, two or three answered follow-ups, transitions and direct shortcuts.
- Paragraph references that reveal the corresponding evidence. Original Arabic Quran passages and named translations use the website's existing connector and one-day cache. Text is not AI-generated or retyped. Source identity is checked before display.
- Exact Sahih al-Bukhari/Muslim and named-scholar source links, including letter suffixes. No reuse of defective stored hadith translations. No inherited approval labels.
- Private device reading marks, undo, resume before marking read, and retained earlier six-step history. Reading is never a conversion requirement or a religious score.
- Actual prayer branches for two, three and four units, complete common instructions and sitting wordings.
