# Ask repair and same-question retest — 22 October 2026

## Verdict

**The Arabic and response-format repairs helped, but the overall answer-completion rate did not improve. Ask is still not ready to call reliable.** The same five questions again produced one complete automatic answer, three incomplete results and one appropriate personal-case referral.

The added validity-consequence protection rejects the recorded false approval offline. The bad fasting-validity sentence did not recur live, but different evidence was selected: the retest used Quran passages rather than that hadith. This is **not proof that the new guard prevented the original error in a real model run**.

Further direct source review found citation/scope problems in the parents explanation and wording that needs qualification in the completed fasting explanation. There is no source-faithfulness acceptance or general accuracy claim.

## What changed

- The active rich checker now uses enforced JSON-schema output. Source-only checks cannot invent whole-answer coverage rows; absent translation candidates cannot generate fictitious translation findings. Existing complete-envelope parsing and all support checks remain required.
- Claims using common legal-validity language receive a separate consequence check in the same checker call. They need the same effect explicitly anchored in a cited original, not a general all-yes vote. A warning about conduct or reward is not proof of invalidity. The server excludes claims without this required proof from streamed safe sections and can withdraw an earlier affected section.
- This is an additional necessary evidence check, **not a complete semantic validator**. It recognises common validity language, relies partly on model effect classification, and cannot guarantee detection of every paraphrase or a changed qualification. Other meanings and source-binding failures still require the ordinary checks. The separate gated focused-checker preview was not activated or accepted by this repair.
- Writing requests now explicitly carry the output language, with Arabic instructions for Arabic output and correction. Repair feedback gives concrete rules for wrong-language drafts and the distinction between uncited study guidance and cited religious instructions.
- The earlier plain-English internal-frame description was restricted to rich/library planning so older JSON clients retain their request contract. The paid rich request behaviour is unchanged by that compatibility repair.
- No model identities, source permissions, patient-worker switches or production deployment changed. No extra checker round, unbounded retry or topic-specific answer was added.

## Important remaining meaning problems

**Parents: correct-looking teaching still needs the correct citations and scope.** One displayed sentence attached the worldly kind-companionship point to Quran 31:14 and 46:15 rather than the directly relevant 31:15. Another expanded the shirk-specific prohibition in 29:8 and 31:15 to all disobedience without citing the broader supporting teaching. This does not establish that the broader teaching is false; it establishes that these particular citations do not support every clause attributed to them. The hadith statement about honouring parents is supported. Sources checked: [31:14](https://quran.com/31/14), [46:15](https://quran.com/46/15), [29:8](https://quran.com/29/8), [31:15](https://quran.com/31/15), [the parents hadith](https://hadeethenc.com/ar/browse/hadith/3365).

**Fasting: the old validity error disappeared, but this is not a clean accuracy pass.** The Quran-only answer described observance as protecting the fasting person from wrongdoing more strongly than the cited tentative purpose warrants. Its summary mostly repeats the source section. Sources checked: [2:183](https://quran.com/2/183), [2:185](https://quran.com/2/185), [2:187](https://quran.com/2/187). The old hadith was not selected, and no live claim triggered the new validity-proof branch.

**Worship: the delivered hadith has direct support, but the visitor still receives no finished answer.** The retest's single delivered statement describes the rights narrated in [the original hadith](https://hadeethenc.com/ar/browse/hadith/65007). Repetitive Quran claims and unsuccessful scholar writing/checking still prevent completion.

## What this leaves to fix

The repairs address concrete contract failures and add a bounded extra protection for one important class of changed meaning. They have **not** fixed the whole system. The next evidence-backed work is accurate claim-to-citation binding and scope checking, followed by selection/writing that explains complementary sources without repetitive padding. Source-service reliability and truly staged processing remain separate problems. Simply relaxing checks to turn these incomplete results into complete answers would hide the remaining defects.
