# Copy-only input isolation: not accepted for website activation

## Implemented

An owner-only transformation narrows a locked text-only source correction to the affected sentence's cited originals and their full restrictive context. It removes unrelated sibling draft prose and unrelated selected passages. Source identity, question, patch layout, normal schema/output/reasoning, six-second timeout and every later safety check remain unchanged. Semantic, merge, summary and unlocked corrections retain their full inputs. Inconsistent original identities are refused.

The actual saved failed hadith correction contained Quran explanations and an unrelated scholar passage about wisdom. That unrelated material was unnecessary for its locked text edit. Its causal role in the earlier bad rewrite is unproven.

## Offline verified

The actual recorded request shrinks from 16,573 to 9,637 prompt characters while retaining the full own hadith and context. Twenty-six focused tests in three files passed for input isolation, identity-locked edits and independent meaning review. A real-engine test injects the transformation only in its owner-only writer wrapper, proving later checks still receive all relevant originals and review the replacement. TypeScript passed. These are mechanical checks, not source-faithfulness proof.

The subsequent full suite passed **1,668 tests in 158 files**, zero failures/skipped tests.

## Live verified and independently reviewed

One saved correction was sent to the current writer with its normal 2,200-token output allowance and six-second timeout. No retrieval, checker, summary or full question was run in this component control.

The result no longer attributes protection to wisdom/pardon and passes the unchanged copying rule. But it misjoins an Arabic noun form to a verb, changes worship to general obedience, and adds a vague good outcome beyond the source's specific non-punishment statement. The complete sentence is not accepted as a natural, precisely supported explanation. A copying pass does not establish meaning.

The active-engine import was removed after review. The helper remains owner-only; no website flag enables it, and no generation will be repeated automatically. Isolation may reduce input, but this run did not establish useful answer-quality improvement.
