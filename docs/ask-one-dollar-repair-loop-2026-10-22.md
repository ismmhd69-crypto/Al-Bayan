## Shared repairs retained

- Completion coverage is keyed by concern, with eligible claim identities enforced in the response contract. Citation lists for each coverage row are derived from those claims, removing contradictory duplicate bookkeeping. Semantic completeness and conditions still require explicit checking.
- Per-claim contribution findings use fixed fields rather than expandable repeated lists. Self-duplication identifiers are excluded. An early version of this repair still permitted self IDs; the online test exposed that mistake and it was corrected.
- The checker selects numbered exact excerpts from each claim's own original passages. Code resolves those selections to the original wording. Unknown or borrowed excerpt IDs fail. Full originals and restrictive context remain available; exact selection never proves semantic support by itself.
- Joint drafts detect summary citations that have not actually been explained. Successful drafts are retained for subsequent corrections. Repairing a source refreshes the dependent summary instead of freezing an older summary sentence.
- Symmetric repetition findings for the same concern can give the existing correction a concrete merge limit. Code does not silently delete religious wording or approve the resulting meaning. The entire corrected draft remains subject to support and coverage checks.
- Invalid later checker responses do not automatically withdraw an independently checked earlier section. Genuine later evidence of lost support still causes withdrawal.
- Semicolons are treated as clause separators, not automatic proof of multiple sentences. Tests retain refusal of unchecked wording after a semicolon, separate full sentences, missing words, negations and unsupported clauses.
- A separate short meaning review checks the exact claims against their own originals. Its output allowance includes reasoning tokens, and positive decisions no longer need verbose explanations. Every proposed surviving claim is eligible for this check even when another claim failed the primary audit. The initial implementation incorrectly skipped that partial-success path; the final offline regression repairs it.

No question-specific answer or religious exception was added. Reference IDs and topic wording appear in evaluation artifacts and regression cases, not production answer rules.

## What still fails

**Meaning and scope.** A selected source can be genuine but narrower than the claim. Examples include a preaching passage generalised to all worship, a particular parental request generalised to every permissible request, an inferred purpose added to a hadith, and qualifiers lost from Quran explanations. Some appeared in retained sections even when the final summary was withheld. These are substantive defects, not cosmetic warnings.

**Correction coordination.** The one correction can be consumed before all later draft problems are known. A repaired first section, rejected remaining section and dependent summary can still end in a mismatched or unsupported final answer. More prompt wording and repeated whole-question attempts have not solved this reliably.

**Optional groups and source selection.** Some selected groups had no usable explanation; some narrow examples were treated as general direct support. The correct response is not to force one answer from each source group. The supported sincerity completion did not need a surviving Quran explanation. Coverage, not source-group quotas, should decide completeness.

**Provider/output failures.** The prayer-versus-supplication attempt ran for 325.807 seconds. Its final meaning request exhausted 1,590 output tokens, including 1,343 reasoning tokens, leaving incomplete JSON. The configured backup then returned a settled, zero-cost HTTP 404/no eligible endpoint. This was not an answer-wide time cutoff. The output-budget repair has a successful settled-request replay; fallback availability was not repaired by loosening privacy.

**Arabic usefulness.** Some drafts have typos, vague study suggestions, repetitive explanations or tautological summaries. An authentic source and a correctly shaped response do not establish useful Arabic teaching. Native-language and source-faithfulness acceptance remain open.

No 30% earlier-first-section improvement is established. Timings varied considerably; round 5's supported sincerity answer first appeared at 39.419 seconds and finished at 39.439 seconds. The slow fresh attempt first displayed a section after 313.934 seconds. Research and first-section timing remain separate unfinished work.
