## Changes

Source explanations now receive only the originals permitted for the sections being written. Each remaining original and its attached restrictive context is unchanged. Unchecked sibling drafts and generated contribution-plan prose are removed from source-writing input. The final summary and combined checks retain the full evidence package and checked explanations.

Two narrow checks run before model checking:

- A short source clause explicitly describes an action followed by a condition. If the explanation repeats that action without accounting for the condition, it needs correction. Other teachings and wording with an explicit condition or limiting language are left to semantic checking. Complementary citations can make the lexical comparison ambiguous, in which case the check abstains.
- The cited originals contain an explicit conditional refusal, but a wider either/or instruction uses terminology found only in another sealed source. That suspicious alternative needs citation-scope correction. The check does not declare the wider teaching false. Ordinary general-scope statements are not rejected merely for using different words.

These checks contain no verse numbers, source IDs, prepared answers or religious-topic dictionary. They do not generate advice. They use the existing bounded correction route; unchanged claims and citations stay locked. A model's positive verdict cannot override a triggered check. If the writer repeats the problematic wording, it remains withheld. A failed summary keeps independently checked earlier sections visible.
